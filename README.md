## ✨ Features & Improvements in v1.1
* **Coordinate Rotation Fixes:** Improved mapping between sensor coordinate space and portrait display space.
* **Auto-Pause on Screen Off:** Automatically stops camera processing when the screen turns off to save battery.
* **Lighting Normalization:** Auto-Exposure Compensation (AEC) shift detection prevents false positive triggers when lighting changes.
* **Reorganized UI:** Separated horizontal and vertical gesture configurations.
