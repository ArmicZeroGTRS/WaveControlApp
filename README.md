---

## ✨ Features in v1.0
* **Front Camera Gesture Tracking:** Left, Right, Up, Down, and Hand Hover detection.
* **Proximity Sensor Detection:** Wave detection over phone screen.
* **Action Mapping:** Media controls (Play/Pause, Next, Prev), Volume control, and System navigation.
* **Foreground Service:** Runs hands-free in the background.
